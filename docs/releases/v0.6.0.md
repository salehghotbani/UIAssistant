# UIAssistant v0.6.0

## English

Screenshots now supports **Full page** and **Select area with mouse**, alongside the existing viewport mode.

- **Full page:** automatically scrolls the main document in both directions, stitches the captured tiles and restores the original scroll position and temporary styles on completion, error or cancellation. Optional fixed/sticky suppression prevents repeated floating headers. A page indicator shows progress; press Esc or Cancel to stop.
- **Selected area:** drag a rectangle directly over the website, including in reverse directions. The capture is cropped to that rectangle with browser-zoom/pixel-scale mapping. Esc cancels without capturing. Selection does not expose screenshot pixels to the injected selector.
- **Workspace:** full-page/area modes open the expanded workspace from a compact popup so the preview survives clicking on the website. Successful capture returns to the workspace. Review locally and manually save PNG/JPEG.
- **Security:** single-use confirmation now binds the selected mode. A confirmed operation has a two-minute deadline, up to 64 tiles, 24 megapixels, 32,760 pixels per side and 24 MB PNG. Every tile retains active-tab/document checks. No new permissions, network services or runtime dependencies; pictures stay out of storage.
- **Validation:** 39 unit/compatibility/security tests plus real Edge checks for reverse area selection at 125% zoom, crop pixels, two-axis full-page stitching, bottom/right pixels, exact scroll/style restoration and cancellation, along with existing screenshot authorization and EN/FA layouts. Firefox packages pass validation; actual Firefox runtime remains untested here.

Full-page capture targets the main scrolling document, not expanded nested scrollers. Infinite/virtualized pages, moving content and closed-shadow floating elements can need manual capture. Dimensions changing during a run abort the result; wait for content to load and retry. The previous unpatched development-only `deepmerge` advisory remains documented in SECURITY.md and is absent from release ZIPs.

Download `UIAssistant.zip` for Chrome/Edge 116+ or `UIAssistant-firefox.zip` for Firefox desktop 140+. These are unsigned developer builds. Reload the extension and inspected pages after replacing files. SHA256SUMS.txt contains both package hashes.

## فارسی

دو حالت **تمام صفحه** و **انتخاب ناحیه با ماوس** به بخش عکس اضافه شدند.

- **تمام صفحه:** اسکرول خودکار سند اصلی در دو جهت، اتصال تصاویر و بازگردانی موقعیت اسکرول و استایل‌های موقت پس از پایان، خطا یا لغو. پنهان‌کردن تکرار عناصر fixed/sticky اختیاری است. نشانگر پیشرفت و لغو با Esc یا دکمهٔ لغو وجود دارد.
- **انتخاب ناحیه:** روی خود وب‌سایت کادر بکشید؛ کشیدن معکوس و زوم مرورگر هم محاسبه می‌شوند. Esc بدون گرفتن عکس لغو می‌کند. تصویر به اسکریپت انتخاب ناحیه فرستاده نمی‌شود.
- **فضای کار:** دو حالت جدید از popup در فضای کار بزرگ باز می‌شوند تا پیش‌نمایش پس از کلیک روی سایت باقی بماند. بعد از ثبت، به فضای کار برمی‌گردید و می‌توانید PNG/JPEG را دستی ذخیره کنید.
- **امنیت:** تأیید یک‌بارمصرف به نوع عکس هم محدود است. هر عملیات حداکثر دو دقیقه، ۶۴ بخش، ۲۴ مگاپیکسل، ضلع ۳۲٬۷۶۰ پیکسل و PNG تا ۲۴MB دارد. بررسی تب فعال و سند برای هر بخش برقرار است. مجوز، سرویس شبکه یا وابستگی اجرایی جدید اضافه نشده و عکس در storage ذخیره نمی‌شود.
- **تست:** ۳۹ تست و آزمون واقعی Edge برای انتخاب معکوس در زوم ۱۲۵٪، رنگ پیکسل برش، اتصال دوطرفه، پیکسل‌های پایین و راست صفحه، بازگردانی دقیق اسکرول/استایل و لغو پاس شده‌اند؛ تست امنیت و نمایش دوزبانه نیز برقرار است. اجرای واقعی Firefox اینجا تست نشده، ولی بستهٔ آن اعتبارسنجی شده است.

عکس کامل برای سند اصلی است و نواحی اسکرول داخلی را باز نمی‌کند. صفحات بی‌نهایت/مجازی، محتوای متحرک و عناصر شناور در shadow بسته ممکن است ثبت دستی بخواهند. تغییر ابعاد حین کار عملیات را رد می‌کند؛ صبر کنید محتوا بارگذاری شود و دوباره امتحان کنید. هشدار قبلی deepmerge فقط در ابزار توسعه باقی است و در بسته‌های انتشار نیست؛ گزارش امنیت جزئیات دارد.

ZIPهای Chrome/Edge و Firefox و checksum منتشر شده‌اند. بسته‌ها بدون امضای فروشگاه‌اند؛ پس از جایگزینی، افزونه و صفحات مورد بررسی را Reload کنید.
