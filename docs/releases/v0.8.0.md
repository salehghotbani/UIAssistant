# UIAssistant v0.8.0

## English

Create more CSS directly in the browser and prepare separate Chrome, Edge and Firefox store submissions.

- **Responsive Grid builder:** choose auto-fit/minimum card width or fixed columns, set row/column gaps, inspect real rendered tracks and copy CSS. Responsive tracks shrink safely to narrow containers.
- **Corner radius builder:** edit all four physical corners, choose px or percent, preview and copy. Invalid ranges disable export.
- **Motion easing editor:** edit cubic-bezier controls, including bounded Y overshoot; play an on-demand preview and copy the CSS timing function. Reduced-motion preferences disable/cancel motion, and leaving the tool cancels its animation.
- **Publication kit:** browser-specific ZIPs, localized manifest descriptions, English/Persian store text, permission/privacy answers, support/privacy URLs, reviewer instructions, a manual QA matrix, ten real 1280×800 screenshots, store icons and promotional graphics. Publisher name is **saleh ghotbani**, with GitHub Issues support and no personal contact email supplied.
- **Reproducible source:** offline build using built-in Node modules, explicit runtime allowlist, matching reviewer ZIP with lockfile and readable DOMPurify sources, plus SHA256SUMS.txt for all six archives. The 128px icon now has transparent store padding. No new runtime dependencies, permissions or network calls.

Validation: **47 unit/compatibility/security tests**; complete real Chrome 156 and Edge integration suites, including clipboard, page tools, all screenshot modes, popup recovery, external/page request denials, the new CSS tools, reduced motion and EN/FA layouts. Firefox passes `web-ext` validation with zero errors/notices/warnings; actual Firefox runtime remains untested here. Browser-specific manual checks are recorded in the publication kit. Source-archive rebuilds are compared byte-for-byte with the released browser ZIPs.

**Store status:** these are prepared, unsigned packages, not approved store listings. Chrome is explicitly on hold and was not uploaded/submitted. Firefox/Edge submission, developer-account contact/identity requirements, remaining manual checks and Mozilla signing remain pending. No personal email was entered, and required store fields are not bypassed. GitHub publication is separate from store approval. See `UIAssistant-publish-kit.zip` or [the publication guide](https://github.com/salehghotbani/UIAssistant/blob/main/docs/publishing/README.md).

Downloads: `UIAssistant-chrome.zip`, `UIAssistant-edge.zip`, `UIAssistant-firefox.zip`; `UIAssistant.zip` retains the previous Chrome/Edge developer-package name. `UIAssistant-source.zip` is for reviewers and `UIAssistant-publish-kit.zip` holds listing/docs/artwork; neither is an installable extension. Minimums: Chrome/Edge 116+, Firefox desktop 140+. Reload the extension and inspected pages after updating.

The previously documented deepmerge advisory remains development-only (one underlying low-severity advisory, three npm dependency-chain entries), outside runtime ZIPs. `npm audit` is not clean; its suggested downgrade to obsolete web-ext 3.2.1 is not applied. Capture and accessibility limits remain as documented.

## فارسی

سه ابزار جدید به کارگاه CSS اضافه شد: **Grid واکنش‌گرا/ثابت** با فاصلهٔ ردیف و ستون، **گردی چهار گوشه** با px/درصد، و **منحنی حرکت cubic-bezier** با پیش‌نمایش اختیاری و رعایت تنظیم کاهش حرکت. همه خروجی قابل کپی و اعتبارسنجی ورودی دارند.

برای هر سه مرورگر ZIP مستقل، معرفی انگلیسی/فارسی، تصاویر واقعی، آیکون فروشگاه، بنر، توضیح مجوز/حریم خصوصی، راهنمای بازبین، فهرست تست دستی و سورس قابل بازسازی آفلاین آماده شده است. نام ناشر **saleh ghotbani** است؛ پشتیبانی از GitHub انجام می‌شود و ایمیل شخصی درج نشده است.

**۴۷ تست** و مجموعهٔ کامل آزمون واقعی Chrome 156 و Edge پاس شدند. بستهٔ Firefox بدون خطا/هشدار اعتبارسنجی شده، ولی اجرای واقعی آن در این محیط تست نشده است. بازسازی بسته‌های مرورگر از سورس ZIP نیز بایت‌به‌بایت بررسی می‌شود.

**انتشار فروشگاهی انجام نشده است.** Chrome طبق درخواست فعلاً ارسال نمی‌شود. Firefox و Edge همچنان به حساب ناشر، الزامات هویت/تماس فروشگاه، بررسی‌های دستی و برای Firefox امضای Mozilla نیاز دارند. ایمیل ساختگی جایگزین الزامات نمی‌شود. Release گیت‌هاب به معنی تأیید فروشگاه نیست.

فایل مخصوص مرورگر را برای نصب/ارسال استفاده کنید؛ ZIP سورس و کیت انتشار افزونهٔ قابل نصب نیستند. پس از به‌روزرسانی افزونه و صفحات را Reload کنید. هشدار کم‌خطر قبلی deepmerge تنها در ابزار توسعه باقی است و در بستهٔ اجرایی وجود ندارد.
