# UIAssistant v0.5.0

## English

Add local viewport screenshots with PNG/JPEG export, and harden screenshot and sampling authorization.

- **Screenshots:** choose the target website, confirm a single capture within 30 seconds, review the local preview and save PNG or JPEG manually. Delete the preview at any time. No automatic downloads, recording, upload or screenshot history; no new permissions. This captures the visible page area, not the full scrolling document or desktop.
- **Security:** explicitly block external extension/site connections; require the exact top-level workspace sender for privileged actions; bind one-use screenshot confirmations and limited sampling/tool sessions to the target document; revoke on navigation/cancellation; recheck the active tab and document before and after capture; reject synthetic page input; restrict storage to trusted contexts where supported; lock down the clipboard offscreen endpoint and runtime CSP.
- **Review:** [SECURITY.md](https://github.com/salehghotbani/UIAssistant/blob/main/SECURITY.md) explains the threat model, fixes, tests and residual limits. Malware, privileged OS/browser automation and compromised extension/browser contexts cannot be blocked by an extension alone.
- **Validation:** 33 unit/compatibility/security tests, isolated Edge integration tests including an actual second extension's rejected screenshot request, forged content-script requests, synthetic input, single-use replay and same-URL navigation rejection, real PNG/JPEG exports, and all eight views/four dialogs in EN/FA at popup/wide/compact sizes. Syntax, formatting, ZIP integrity and Firefox lint pass. Firefox runtime and native screen EyeDropper remain untested here.
- **Dependency caveat:** npm reports one low-severity unpatched `deepmerge` advisory through development-only `web-ext`/`addons-linter` (three package entries). These packages are absent from release ZIPs; the audit is not claimed to be completely clean. Details and advisory link are in the security report.

Download `UIAssistant.zip` for Chrome/Edge 116+ or `UIAssistant-firefox.zip` for Firefox desktop 140+. Both are unsigned developer builds; Firefox permanent installation requires Mozilla signing. `SHA256SUMS.txt` contains both ZIP hashes. Reload the extension **and inspected pages** after replacing files so old injected scripts are removed.

## فارسی

گرفتن عکس محلی از بخش نمایان صفحه با خروجی PNG/JPEG اضافه شد و مجوز عکس و نمونه‌گیری سخت‌گیرانه‌تر شد.

- **عکس از صفحه:** صفحهٔ هدف را انتخاب، ظرف ۳۰ ثانیه یک عکس را تأیید، پیش‌نمایش محلی را بررسی و فایل را دستی ذخیره کنید. پیش‌نمایش قابل حذف است؛ دانلود خودکار، ضبط، آپلود، تاریخچهٔ عکس یا مجوز جدیدی وجود ندارد. فقط بخش نمایان صفحه ثبت می‌شود، نه تمام طول صفحه یا دسکتاپ.
- **امنیت:** اتصال خارجی بسته، فرستندهٔ فضای کار دقیق بررسی، تأیید عکس یک‌بارمصرف و نشست نمونه‌گیری/ابزار به سند هدف محدود، و با تغییر صفحه یا لغو باطل می‌شود. تب و سند قبل و بعد تصویر بررسی می‌شوند؛ رویداد جعلی صفحه رد، storage در مرورگر پشتیبان محدود، و مسیر کلیپ‌بورد و CSP سخت‌گیرانه شده‌اند.
- **گزارش:** [SECURITY.fa.md](https://github.com/salehghotbani/UIAssistant/blob/main/SECURITY.fa.md) شامل اصلاحات، تست‌ها و محدودیت‌هاست. افزونه به‌تنهایی نمی‌تواند بدافزار، اتوماسیون دارای دسترسی سیستم/مرورگر یا بافت نفوذشده را متوقف کند.
- **بررسی:** ۳۳ تست محاسباتی/سازگاری/امنیت، آزمون واقعی Edge با افزونهٔ دومِ درخواست‌کنندهٔ عکس، پیام جعلی، رویداد ساختگی، تکرار تأیید، Reload همان آدرس، خروجی واقعی PNG/JPEG و ۸ صفحه و ۴ پنجره در دو زبان و سه اندازه پاس شده‌اند. اجرای واقعی Firefox و EyeDropper بومی اینجا تست نشده‌اند.
- **مورد باقی‌مانده:** یک هشدار کم‌خطر بدون اصلاح رسمی در `deepmerge` ابزار توسعهٔ web-ext وجود دارد و داخل ZIPها نیست؛ گزارش امنیتی جزئیات دارد و audit کاملاً پاک ادعا نمی‌شود.

دو ZIP برای Chrome/Edge و Firefox و فایل checksum همراه انتشارند. بسته‌ها بدون امضای فروشگاه‌اند؛ نصب دائمی Firefox استاندارد به امضای Mozilla نیاز دارد. پس از جایگزینی فایل‌ها، افزونه **و صفحات مورد بررسی** را Reload کنید تا اسکریپت تزریق‌شدهٔ قدیمی پاک شود.
