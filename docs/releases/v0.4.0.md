# UIAssistant v0.4.0

## English

This release adds a CSS workshop and accessibility basics, and reviews every workspace page and dialog for spacing, icons and English/Persian layouts.

- **CSS workshop:** px ↔ rem with a configurable root size, fluid `clamp()` CSS with a viewport preview, and a box-shadow builder with signed offsets, blur, spread, color, opacity and inset. Copy generated CSS directly.
- **Accessibility basics:** preliminary checks for missing image alternatives, unnamed controls, missing page language and heading-level jumps. Associated labels, ARIA names and decorative empty alt values are accounted for. These are review hints, not a complete accessible-name implementation or WCAG verdict.
- **Reports:** export inspection, measurement, token and audit results as local JSON.
- **Interface:** local decorative SVG icons on every app button, consistent action gaps, wrapping toolbars, compact gradient rows, full-width gradient presets, improved text contrast, responsive navigation and scrollable dialogs.
- **Languages:** frontend navigation survives language changes; Persian gradient types, preview labels and adjustment controls are translated.
- No new permissions, runtime dependencies, network services or GPU compute APIs. CSS calculations and DOM checks use JavaScript on the CPU; browser rendering can still use hardware acceleration.

Validation: 24 unit/compatibility tests; isolated Edge integration tests including real clipboard, all nine frontend tools, CSS utilities, report export, and all seven pages/four dialogs in English and Persian at popup (790×600), wide (1100×800) and compact (480×800) sizes. Scrolled sections are checked for button spacing and horizontal overflow. JavaScript syntax, formatting, ZIP integrity and Firefox `web-ext` validation pass. Actual Firefox runtime and native screen EyeDropper remain untested in this environment.

### Downloads

- `UIAssistant.zip`: extract and load unpacked in Chrome/Edge 116+.
- `UIAssistant-firefox.zip`: Firefox desktop 140+, temporary installation through `about:debugging`.
- `SHA256SUMS.txt`: SHA-256 checksums for both ZIPs.

These are unsigned developer builds, not extension-store releases. Permanent installation in standard Firefox requires Mozilla signing. Replace the old extracted files, reload the extension and reload inspected pages.

## فارسی

این نسخه کارگاه CSS و بررسی مقدماتی دسترس‌پذیری را اضافه می‌کند و چیدمان، فاصله‌ها و آیکون‌های تمام صفحات و پنجره‌ها را در فارسی و انگلیسی بازبینی می‌کند.

- **کارگاه CSS:** تبدیل px/rem با ریشهٔ دلخواه، تولید `clamp()` با پیش‌نمایش عرض، و ساخت سایه با فاصله، محوشدگی، گسترش، رنگ، آلفا و حالت داخلی؛ کپی مستقیم CSS.
- **اصول دسترس‌پذیری:** بررسی متن جایگزین تصویر، نام کنترل، زبان صفحه و پرش سطح عنوان؛ پشتیبانی از برچسب مرتبط، نام ARIA و alt خالی تزئینی. نتیجه‌ها مقدماتی‌اند و جای ارزیابی انسانی و کامل WCAG را نمی‌گیرند.
- **گزارش:** خروجی JSON محلی برای بازرسی، اندازه‌گیری، توکن‌ها و بررسی‌ها.
- **رابط:** آیکون SVG محلی روی تمام دکمه‌های برنامه، فاصلهٔ منظم، شکستن ردیف‌های شلوغ، چیدمان مرتب نقاط گرادیان، الگوهای تمام‌عرض، متن خواناتر و ناوبری مناسب پنجرهٔ باریک.
- **دوزبانه:** حفظ صفحهٔ فعال هنگام تغییر زبان و تکمیل ترجمهٔ نوع گرادیان، پیش‌نمایش و تنظیم رنگ.
- مجوز، وابستگی اجرایی، سرویس شبکه یا محاسبات اختصاصی GPU اضافه نشده است. محاسبات CSS و بررسی DOM روی CPU هستند؛ رندر مرورگر می‌تواند از شتاب سخت‌افزاری استفاده کند.

۲۴ تست محاسباتی/سازگاری، تست واقعی Edge برای کلیپ‌بورد، ۹ ابزار فرانت‌اند، کارگاه CSS و گزارش، و هر ۷ صفحه و ۴ پنجره در دو زبان و سه اندازه پاس شده‌اند؛ بخش‌های پایین صفحه نیز با اسکرول بررسی می‌شوند. ساختار JavaScript، قالب‌بندی، سلامت ZIP و اعتبارسنجی Firefox بررسی شده‌اند. اجرای واقعی Firefox و EyeDropper بومی در این محیط تست نشده‌اند.

دو ZIP برای Chrome/Edge و Firefox و فایل checksum همراه انتشار هستند. نسخه‌ها بدون امضای فروشگاه‌اند؛ Firefox استاندارد برای نصب دائمی به امضای Mozilla نیاز دارد. پس از جایگزینی فایل‌ها، افزونه و صفحات مورد بررسی را Reload کنید.
