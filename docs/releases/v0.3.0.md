# UIAssistant v0.3.0

## English

The first public developer release includes the color workspace and eight frontend tools: element inspection, typography, spacing ruler, layout findings, text contrast with suggestions/manual-review flags, CSS/JSON design tokens, local reference-image overlays and reversible RTL/LTR preview.

- Every selected color is copied automatically; the existing history and palette workflows remain available.
- Separate Chrome/Edge and Firefox packages, English/Persian UI and bilingual documentation with actual screenshots.
- MIT-licensed first-party source; DOMPurify notices preserved in the source and ZIPs.
- Validation: 20 unit/compatibility tests, isolated Edge integration coverage for color and all eight frontend tools, syntax/format checks and Firefox web-ext validation. Firefox runtime and native screen EyeDropper have not been tested here.

### Assets

- `UIAssistant.zip`: extract and load unpacked in Chrome/Edge 116+.
- `UIAssistant-firefox.zip`: Firefox desktop 140+, temporary installation through about:debugging.
- `SHA256SUMS.txt`: SHA-256 checksums for both ZIPs.

These are unsigned developer packages, not extension-store releases. Permanent Firefox installation requires Mozilla signing. Read the README for protected-page, frame, font, contrast and scanning limits.

## فارسی

اولین انتشار عمومی توسعه‌دهنده شامل فضای کار رنگ و هر هشت ابزار فرانت‌اند است: بازرسی عنصر، تایپوگرافی، خط‌کش، بررسی چیدمان، کنتراست با پیشنهاد/بررسی دستی، توکن CSS/JSON، تصویر مرجع محلی و پیش‌نمایش قابل بازگردانی RTL/LTR.

- هر رنگ انتخاب‌شده خودکار کپی می‌شود؛ تاریخچه و پالت‌ها حفظ شده‌اند.
- بستهٔ جداگانهٔ Chrome/Edge و Firefox، رابط و مستندات فارسی/انگلیسی و تصاویر واقعی.
- مجوز MIT برای سورس پروژه؛ حفظ اعلان‌های DOMPurify در سورس و ZIP.
- بررسی: ۲۰ تست محاسباتی/سازگاری، تست یکپارچهٔ Edge برای رنگ و هشت ابزار، بررسی ساختار/قالب‌بندی و اعتبارسنجی Firefox. اجرای واقعی Firefox و EyeDropper بومی در این محیط تست نشده‌اند.

دو ZIP برای مرورگرها و فایل SHA256SUMS.txt برای کنترل سلامت ارائه شده‌اند. بسته‌ها نسخهٔ توسعه‌دهندهٔ بدون امضا هستند؛ نصب Firefox فعلاً موقت است و نصب دائمی امضای Mozilla می‌خواهد. محدودیت‌های ابزار در README آمده است.
