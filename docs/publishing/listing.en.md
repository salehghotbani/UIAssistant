## Full description

UIAssistant helps frontend developers inspect and recreate interface details in the browser. Work with colors, CSS and page screenshots locally, with English and Persian interfaces.

- Pick real page pixels with a magnifier, adjustable sample size or area averaging. Color selections copy automatically in your chosen CSS format.
- Edit colors and gradients; save palettes and export CSS/JSON.
- Inspect element dimensions, typography, spacing, borders and shadows. Measure the gap between two elements and copy computed styles.
- Review overflow, clipped text and basic accessibility/contrast findings. Export design tokens and review reports.
- Compare a page with a local reference image and preview RTL/LTR layout changes.
- Generate px/rem conversions, fluid type, box shadows, responsive CSS Grid, four-corner border radii and cubic-bezier motion curves with previews and copyable CSS.
- Capture the visible page, stitch the whole document, drag-select a region or capture a chosen internally scrolling panel. Review the result and save PNG/JPEG manually. Open the toolbar popup again if the browser closes it while you select a target.

No account, subscription, analytics or server upload. Tools run locally. Temporary screenshot results stay in bounded memory for up to five minutes; navigation/closure of the source page clears them. Saved palettes/settings remain in the browser profile until deleted. Clipboard write access supports color/CSS copy; UIAssistant does not read your clipboard.

Page tools act on the site you explicitly choose and require permission through the browser. Protected browser/store pages are restricted. Accessibility checks are preliminary and need human review. Full-page/panel capture is limited to 64 tiles, 24 megapixels and two minutes; infinite or virtualized content may need manual capture. Native screen-wide color picking depends on browser support.
